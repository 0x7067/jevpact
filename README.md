# Jevpact

> Compact Codex at the right moment.

Jevpact is a local, open-source Codex plugin that requests native compaction at useful work transitions and continues actionable work after completion. It is a macOS development preview.

Free forever ♡ · by [Slopware Engineer](https://x.com/aienginerd). A TypeSafe Jev API account may have its own charges.

## Package

| Package | Type | Purpose |
| --- | --- | --- |
| [Jevpact](plugins/jevpact/README.md) | Codex plugin and local service | Watch task state, choose compaction checkpoints, observe native completion, and resume actionable work. |

The [package README](plugins/jevpact/README.md) has the full install, update, and removal commands. [Privacy and data handling](plugins/jevpact/docs/privacy.md) explains the external Jev request and local diagnostic history.
